# IYKFixitMobile Website

This is a static, mobile-responsive website for IYKFixitMobile.

## Important before publishing
1. Replace the WhatsApp placeholder with the current business WhatsApp number.
2. If you have a logo image, replace the text mark in the header with your logo.
3. Review inventory before publishing because prices/availability can change.
4. Add the final legal business name/details required by your WhatsApp API provider.

## Free hosting
GitHub Pages can host this static site for free on a github.io address. A custom domain can be connected later.
